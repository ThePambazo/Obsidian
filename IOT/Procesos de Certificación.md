
Los procesos de certificación  involucra control  efectuados por las redes de comunicación.

Cada red de comunicación (Sigfox LoRa CSA) cuentan con normas y especificaciones / características para tener una buena transmisión de datos en la red de comunicación

La certificación garantiza que la transmisión de datos a través de la  red de comunicación se encuentra en óptimas condiciones.

Cada dispositivo tiene su certificación
- Sensor de temperatura: certificación especial (otra norma)
